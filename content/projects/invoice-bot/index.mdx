## How it works

Every photo goes through three steps: **extract**, **validate**, **file**.
Extraction uses a vision model with a strict JSON schema. Validation is plain
code: totals must add up, dates must be in the past, vendors are matched
against the ones you've seen before.

```ts
const invoice = InvoiceSchema.parse(await extract(photo));
if (invoice.confidence < 0.8) await askToConfirm(invoice);
await sheet.append(toRow(invoice));
```

## What I learned

Asking one precise question beats showing a form. Users confirm a single field
in a tap, but abandon a five-field review screen.
